## 2026-06-17 yeniləməsi — 2026-06-05 tarixindən bəri nələr dəyişib

50 agentli veb araşdırma mərhələsi (rəsmi sənədlər + son 7 günün xəbərləri, ziddiyyətli yoxlama ilə) bütün kataloqu yenilədi. Əsas məqamlar:

- **Silinib / pulsuz səviyyə yoxdur (2026):** `chutes` (pulsuz səviyyə 2026-03 tarixində başa çatdı), `phind` (şirkət 2026-01 tarixində fəaliyyətini dayandırdı), `kluster` (2026-06-09 tarixində dayandırıldı → MITO), `gitlawb` + `gitlawb-gmi` (MiMo pulsuz girişi 2026-05-24 tarixində ləğv edildi, Nemotron kampaniyası 2026-06 tarixində başa çatdı — 2026-06-18 tarixində yenidən yoxlanıldı), `aimlapi` (pulsuz səviyyə dayandırılıb — 2026-06-18 tarixində yenidən yoxlanıldı), `yi` (Yi-Light istifadədən çıxarılıb, istifadə qədər ödəniş tətbiq olunur — 2026-06-18 tarixində yenidən yoxlanıldı), `featherless-ai` (hazırda pulsuz səviyyə yoxdur). `iflytek` / `sparkdesk` siyahıda qalır, lakin ToS ilə bağlı xəbərdarlıq qeydi daşıyır (Spark Lite pulsuzdur; ToS proksi/retranslyator istifadəsini məhdudlaşdırır).
- **Gemini** — `2.0 Flash` / `2.0 Flash-Lite` 2026-06-01 tarixində dayandırıldı və `2.5 Pro` pulsuz səviyyədən çıxarıldı (2026-04); pulsuz səviyyə indi **yalnız Flash ailəsindən** ibarətdir (2.5/3/3.1/3.5 Flash + Gemma). Kataloq artıq Flash ailəsini **vahid hovuzda birləşdirir** (əvvəllər hər variant ayrıca hesablandığı üçün rəqəm süni şəkildə şişirdilmişdi: 462M → 60M).
- **Düzəldilmiş rəqəmlər:** `cloudflare-ai` 122M → **30M** (real limit gündə 10k Neuron), `doubao` təkrarlanan deyil, birdəfəlik qeydiyyat krediti kimi yenidən təsnif edildi, `llm7` 4M → **150M** (sənədləşdirilmiş gündə 5M token), `together` "-Free" son nöqtələri dayandırıldı → $25 qeydiyyat krediti də silindi (minimum $5 alış tələb olunur, pulsuz sınaq yoxdur), `longcat` Preview başa çatdı + Flash modelləri istifadədən çıxarıldı → yalnız **LongCat-2.0**, birdəfəlik **10M** tokenlik qeydiyyat krediti kimi yenidən təsnif edildi (KYC tələb olunur, təkrarlanan deyil).
- **Aşkarlanmış yeni pulsuz provayderlər:** ⭐ **Kilo Code** (`kilo-gateway` — rotasiya olunan "Auto Free" dəsti: NVIDIA Nemotron 3 ailəsi, StepFun, Poolside, Nex-N2-Pro), ⭐ **OpenCode Zen** (`opencode-zen` — rotasiya olunan 6 pulsuz kodlaşdırma modeli), ⭐ **Z.AI / Zhipu** (`glm-cn` — GLM-4-Flash / 4.5-Flash / 4.7-Flash daimi pulsuzdur + 20M qeydiyyat bonusu) və `arcee-ai` Trinity Large Preview.
- **Yeni şəffaf səviyyələr** (Metodologiyaya baxın): _daimi pulsuz, lakin limitsiz_ kateqoriya (real təkrarlanan giriş, hesablanacaq token limiti yoxdur) və _depozitlə açılan artım_ (OpenRouter $10 → +24M/ay); əsas göstəricini heç vaxt şişirtməmələri üçün hər ikisi **ayrıca** göstərilir.

> Aşağıdakı provayderlər üzrə ətraflı cədvəl **2026-06-05 anlıq görüntüsüdür**; yuxarıdakı dəyişikliklər onu əvəz edir. Aktual, kanonik mənbə model üzrə tərtib edilmiş `open-sse/config/freeModelCatalog.ts` kataloqudur.

## İki rejim — hesablama və qərarvermə

OmniRoute "pulsuzdurmu?" sualını qəsdən fərqli mənbələri oxuyan iki rejim vasitəsilə cavablandırır:

| Rejim                    | Həqiqət mənbəyi                                                                                                                                                                                        | Tətbiq olunduğu yerlər                                                                                                                             |
| ------------------------ | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------ | -------------------------------------------------------------------------------------------------------------------------------------------------- |
| **Hesablama / göstərmə** | Həll edilmiş kataloq — Radar axını (`getRadarCatalog`) ilə üst-üstə tətbiq olunan buraxılışa daxil edilmiş baza                                                                                        | Pulsuz səviyyə üzrə ümumi göstəricilər, büdcə kartı, idarəetmə panelləri                                                                           |
| **Qərarvermə**           | Yalnız buraxılışa daxil edilmiş kataloq (`open-sse/config/freeModelCatalog.data.ts` daxilində `FREE_MODEL_BUDGETS`) və lokal evristikalar (`:free` suffiksi, sıfır qiymətləndirmə, `grantsFreeAccess`) | `src/shared/utils/freeModels.ts` faylının hər bir istehlakçısı: model idxalı, `auto/*` marşrutlaşdırması, `GET /v1/models` və brauzer önizləmələri |

Axın əlçatan olduqda hesablama təkmilləşə bilər. Qərarvermə isə buraxılış artefaktına əsaslanmağa davam edir; beləliklə, cavab brauzerdə və serverdə eyni olur, oflayn rejimdə təkrarlana bilir və verilənlər bazası olmadan sınaqdan keçirilə bilir. Brauzer önizləməsinin bir mənbəni, server idxalının isə digərini oxumasına icazə vermək, klik zamanı baş verənlərlə ziddiyyət təşkil edən önizləmə yaradardı — bu bölgü qəsdən saxlanılır.

## Metodologiya və qeydlər

- Rəqəmlər veb araşdırması ilə toplanmış, hər bir provayderin **2026-06-17** tarixinə sənədləşdirilmiş pulsuz səviyyə limitlərinə əsaslanan **yuxarı hədd təxminləridir**. Pulsuz səviyyələr daim dəyişir — hər hansı rəqəmə etibar etməzdən əvvəl onu yenidən yoxlayın.
- **Hər bir qeydin əslində nəyi təsdiqlədiyi.** Heç bir qeydin sətir üzrə etibarlılıq reytinqi yoxdur və API də belə bir reytinq təqdim etmir — yuxarıdakı bütün rəqəmləri eyni, açıqlanmamış keyfiyyətə malik təxminlər kimi qəbul edin. İki fakt fərqlidir, çünki onlar nəticə çıxarılmaq əvəzinə əl ilə seçilib: 5 qeyddə müstəqil şəkildə sənədləşdirilmiş sərt dayandırma, 13 qeyddə isə sorğuların təlim üçün istifadəsinə dair açıqlama var. `hardStopGuaranteed` yalnız provayderin öz şərtlərində pulsuz limitin aşılmasının sizə səssizcə ödəniş yazmağa başlamaq əvəzinə sorğunu rədd etdiyi bildirildikdə təyin olunur və mənbə qeydin yanındakı şərhdə göstərilir; onun dəyəri heç vaxt standart olaraq `true` təyin edilmir və heç kimin yoxlamadığı qeyddə bu sahə təyin edilməmiş qalır. Buna görə sərt dayandırma bayrağının olmaması «müəyyən edilməyib» deməkdir, «sizə ödəniş yazıldığı məlumdur» yox. **STRICT rejimi** (seçim əsasında aktivləşdirilən `freeAccessPolicy=strict` marşrutlaşdırma qoruyucusu) yalnız bu bayrağı daşıyan qeydlərə etibar edir; bütün digər pulsuz səviyyələr `no-hard-stop` səbəbi ilə istisna edilir (baxın: `open-sse/services/autoCombo/strictZeroCostFilter.ts`).
- `estMonthlyFreeTokens` = yalnız hər ay yenilənən tokenlər. **Qeydiyyat zamanı verilən birdəfəlik kreditlər yenilənmir** və 0 kimi hesablanır. Dayandırılmış səviyyələr də 0-dır.
- Gündəlik token həddi → `monthly = daily × 30`. Yalnız RPD sənədləşdirilibsə → `RPD × ~800 çıxış tokeni × 30`. Yalnız RPM/TPM varsa (gündəlik hədd yoxdur) → **hədsiz** (aşağıya baxın).
- **Daimi pulsuzdur, lakin dərc edilmiş token həddi yoxdur** (`siliconflow`, `glm-cn`, `tencent`, `baidu`, `kilo-gateway`, `opencode-zen`, `gemini`, `ollama-cloud`): bunlar sürət/paralellik baxımından məhdudlaşdırılmış real, təkrarlanan pulsuz giriş imkanlarıdır. Biz onları `recurring-uncapped` kimi təsnif edir və **heç vaxt cəmləmirik** — `RPM × 24/7 × 30d` hesablaması qeyri-real bir yuxarı hədd yaradardı (biz məhz bu şişirtməni rədd edirik). Onlar mövcud olduqlarını bilməyiniz üçün siyahıya daxil edilib.
- **Depozitlə açılan artım:** pulsuz kvotanı daimi olaraq artıran kiçik, birdəfəlik balans artırımı (OpenRouter: $10 → gündə 1000 sorğu ≈ +24M/ay). Ayrı bir rəqəm kimi göstərilir və sabit əsas göstəriciyə daxil edilmir.
- **Uyğunluq şərtli kvotalar** (`eligibilityGate: "regional-identity"`): yalnız regionla əlaqəli şəxsiyyət yoxlamasından sonra açılan real, təkrarlanan kvota (hazırda materik Çində həqiqi adla təsdiqləmə). Eyni hovuz deduplikasiyası qaydası ilə ayrıca rəqəmdə (`gatedRecurringTokens`) hesablanır və heç vaxt sabit əsas göstəriciyə daxil edilmir. Rejim (`freeType`) dəyişmədiyi üçün marşrutlaşdırma da dəyişmir.
- **Sübut sinifləri.** Qayda belədir: kataloqdakı rəqəm mənbəsini qeydin yanındakı `// evidence:` şərhində göstərir — `public-page` (hər kəsin oxuya biləcəyi provayder səhifəsi), `api-public` (provayderin autentifikasiya tələb etməyən son nöqtəsi, məsələn, NaraRouter-in router.bynara.id ünvanındakı ictimai planlar son nöqtəsi) və ya `console-verified <date> por <who>` (rəqəm yalnız hesab konsolunda görünür; şərhdə onu kimin və nə vaxt gördüyü, həmçinin həddin mövcud olduğunu bildirən ictimai səhifə qeyd olunur). Hazırkı vəziyyət belədir: 2026-09-02 tarixində yenidən audit edilmiş beş blokda bu məlumat var (`gemini`, `groq`, `mistral`, `ollama-cloud`, `nara`); 2026-09-02 tarixli təkrar auditdən əvvəl yaradılmış qeydlər yenilənənədək əvvəlki araşdırmanın nəticələrini miras alır; sübut şərhi olmayan istənilən **yeni və ya dəyişdirilmiş** rəqəm xətadır. Hazırda yalnız `mistral` konsolda təsdiqlənib.

## Niyə bizim rəqəmimiz digər aqreqatorların rəqəmlərindən daha kiçikdir

Bu sahədəki əksər "aylıq pulsuz tokenlər" göstəriciləri model üzrə etiketlərin cəmidir. Bizimki isə məqsədli şəkildə belə deyil:

- **Hər ortaq hovuz yalnız bir dəfə hesablanır.** Mistral-ın pulsuz planı hər təşkilat üçün aylıq 1B həcmində vahid limitdir; onu beş model altında göstərmək bu limiti 5B etmir. Model üzrə cəmləndirilsəydi, öz kataloqumuz **~7.4B** göstərərdi (2026-09-03 tarixində yenidən hesablanıb; bu göstərici CI tərəfindən yoxlanılmır — kataloq hər dəyişəndə onu yenidən ölçün) — başlıqda **~1.47B** göstərilir, çünki hər provayderdəki bir hesabın faktiki istifadə edə biləcəyi həcm budur.
- **Gündəlik limitlər çevrilir, sürət limitləri isə yox.** Sənədləşdirilmiş token/gün limiti `× 30` kimi hesablanır; sənədləşdirilmiş sorğu/gün limiti `RPD × ~800 token × 30` kimi hesablanır; yalnız dəqiqədə sorğu sayını dərc edən provayder üçün aylıq göstərici **yoxdur** və o, _limitsiz_ kimi göstərilir, heç vaxt cəmə daxil edilmir. Sürət limitini 24/7 rejiminə vurmaq bizim yol vermədiyimiz şişirtmədir.
- **Regional şəxsiyyət yoxlamasının arxasında olan kvotalar ayrıca göstərilir** (`+~6M regional şəxsiyyət təsdiqindən sonra`), çünki əksər oxucular onlardan istifadə edə bilmir.
- **Qeydiyyat kreditləri yalnız ilk ay üçündür** və sabit göstəriciyə heç vaxt daxil edilmədən ikinci rəqəm kimi təqdim olunur.
- **Göstəricinin düzgünlüyü CI tərəfindən təmin edilir.** `npm run check:docs-counts` ümumi göstəriciləri kataloqdan yenidən hesablayır və bu fayldakı, README-dəki və ya büdcə kartındakı rəqəmlər onlardan fərqləndikdə yığmanı uğursuz edir.

Provayder hələ də təxminən 80 daimi pulsuz modeli host edir, lakin ToS (Bölmə 4.3(d)) Xidmətlərin ötürülməsini, paylanmasını, yenidən satılmasını və ya təklif edilməsini açıq şəkildə qadağan edir.
- **`uncloseai`** — Əsasən uyğundur — hələ də həmişəlik pulsuzdur və qeydiyyat tələb etmir. Bununla belə, ToS (terms-of-use.html) həddindən artıq istifadə üçün IP əsaslı məhdudlaşdırmanın mövcud olduğunu aydınlaşdırır və rəqib ML xidmətlərinin qurulmasını qadağan edir…
- **`veoaifree-web`** — Təqdim edilən freeNote-da "saatda 6 sorğu" yazılıb, lakin hazırda veoaifree.com saytında belə açıq limit heç yerdə sənədləşdirilməyib. Sayt giriş tələb etmədən limitsiz pulsuz generasiya təklif etdiyini iddia edir. Siyahıya alınan modellər…
- **`voyage-ai`** — Təqdim edilən "Embeddinq və yenidən sıralama üçün 200M pulsuz token" freeNote-u token sayı baxımından ümumi istiqamət üzrə doğrudur, lakin yanıltıcıdır — bunun təkrarlanan deyil, hər hesab üçün birdəfəlik ayrılma olduğu göstərilmir…
- **`yi`** — Təqdim edilən "Pulsuz Yi-Light modelləri" freeNote-u cari 01.AI sənədlərində və ya model kataloqunda görünməyən model adına ("Yi-Light") istinad edir — platform.01.ai saytında belə bir model göstərilmir, …
