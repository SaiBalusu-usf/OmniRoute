## Àwọn Ẹ̀ka

- **Ọ̀fẹ́** — ipele ọ̀fẹ́ pẹ̀lú kọ́kọ́rọ́ API (tí a ṣètò nípasẹ̀ dashboard)
- **Láìsí ìfàṣẹsí** — àwọn endpoint gbogbogbò tí kò nílò kọ́kọ́rọ́ tàbí wíwọlé rárá
- **OAuth** — OmniRoute ló ń bójú tó ìlànà wíwọlé, kò nílò kọ́kọ́rọ́ API
- **Kúkì wẹ́ẹ̀bù** — ń ṣàkóso app wẹ́ẹ̀bù olupèsè náà nípasẹ̀ ìfàṣẹsí kúkì
- **Kọ́kọ́rọ́ API** — olupèsè aláyédèrú tí a ṣètò nípasẹ̀ kọ́kọ́rọ́ API (àwọn kírẹ́díìtì ọ̀fẹ́ lè wà)
- **Agbègbè** — ń ṣiṣẹ́ lórí ẹ̀rọ aṣàmúlò (Ollama, LM Studio, vLLM, àti bẹ́ẹ̀ bẹ́ẹ̀ lọ.)
- **Ìṣàwárí** — àwọn olupèsè ìṣàwárí wẹ́ẹ̀bù
- **Ohùn** — àwọn olupèsè ohùn nìkan (TTS/STT)
- **Aṣojú òkè** — àwọn olupèsè tí ń ṣe aṣojú sí àwọn olupèsè mìíràn
- **Aṣojú àwọsánmọ̀** — àwọn aṣojú kíkọ kóòdù tí ń ṣiṣẹ́ fún ìgbà pípẹ́ (Codex Cloud, Devin, Jules)
- **Ètò** — àwọn olupèsè inú OmniRoute (loopback, àti bẹ́ẹ̀ bẹ́ẹ̀ lọ.)

Àwọn àmì àfikún: `image`, `video`, `aggregator`, `enterprise`, `embed/rerank`, `self-hosted`.

`Pípè irinṣẹ́` (níbi tí a bá fi hàn): `native` — API pípè iṣẹ́ gidi; `emulated` — a ń ṣe àfarawé àkójọpọ̀ `tools` nípasẹ̀ prompt pẹ̀lú `webTools.ts` (àwọn ìdípọ̀ `<tool>{...}</tool>` tí a ṣàyẹ̀wò pẹ̀lú regex); `none` — lọ́wọ́lọ́wọ́, a máa ń fi `tools` sílẹ̀ ní ìdákẹ́jẹ́. Wo #7286.

Lo dashboard ní `/dashboard/providers` láti mú olupèsè kọ̀ọ̀kan ṣiṣẹ́, ṣètò rẹ̀, àti láti dán an wò.
