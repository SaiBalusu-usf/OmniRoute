## Укратко — колико бесплатног закључивања OmniRoute заправо обједињује?

| Метрика                                           | Токена месечно               | Значење                                                                                                                                                                                                                                                                                                                                                       |
| ------------------------------------------------- | ---------------------------- | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| **Документована периодична квота (стално)**       | **~1,47 млрд.**              | **Скупови** бесплатних нивоа (каталог по моделу), при чему се сваки дељени скуп рачуна **једном**. Актуелни извор података за `/api/free-tier/summary` и страницу „Буџет бесплатног нивоа“ на контролној табли. **Користите овај број.**                                                                                                                      |
| **+ први месец са кредитима за регистрацију**     | **~2,07 млрд.**              | Стална квота + једнократни кредити за регистрацију (Z.AI 20M, DeepSeek 5M, …), уз уклањање дупликата по налогу. **Само првог месеца** — не обнавља се.                                                                                                                                                                                                        |
| **+ трајно бесплатно, без објављеног ограничења** | _није могуће квантификовати_ | `siliconflow`, `glm-cn` (GLM-4-Flash), `tencent`, `baidu`, `kilo-gateway`, `opencode-zen`, `gemini`, `ollama-cloud` — стваран периодичан приступ, ограничен брзином/истовременим захтевима, **без ограничења токена које би се могло рачунати**. Наводе се, али се никада не сабирају (рачунање по формули `RPM×24/7` представља надувавање које одбацујемо). |
| **+ повећање након уплате**                       | **+~24M**                    | Једнократна допуна OpenRouter налога од **$10** повећава његов бесплатни скуп са 50 → 1000 захтева дневно. Приказује се засебно како никада не би увећавала стални број.                                                                                                                                                                                      |
| **+ иза регионалне провере идентитета**           | **+~6M**                     | `modelscope` (повезивање са Alibaba Cloud налогом + верификација правог имена у континенталној Кини). Стварна периодична квота, изложена као `gatedRecurringTokens` / `gatedProviders` и приказана на контролној табли. Никада се не сабира са главним бројем: +~6M иза регионалне провере идентитета.                                                        |
| Теоријски максимум (сва ограничења брзине, 24/7)  | ~10 млрд.                    | Збир ограничења брзине свих добављача, екстраполиран на непрекидно коришћење. **Није гаранција** — немојте ово истицати као главни податак.                                                                                                                                                                                                                   |

**Искрен главни податак:** _OmniRoute обједињује **~1,47 милијарди документованих бесплатних токена месечно** (до ~2,07 милијарди током првог месеца са кредитима за регистрацију) у оквиру 34 скупа бесплатних нивоа — уз дугачак низ трајно бесплатних добављача без ограничења — док RTK + Caveman компресија (уштеда од 15–95% токена) то додатно проширује._

> **Зашто је овај број мањи од претходних ~1,94 милијарде.** Освежење од 2026-06-17 представља исправку ради тачности, а не губитак: за `gemini` су сада уклоњени дупликати из заједничког скупа (раније је број био надуван засебним рачунањем сваке Flash варијанте, 462M → 60M), `cloudflare-ai` је исправљен на стварних 10 хиљада Neurons дневно (122M → 30M), `doubao` је прекласификован као једнократни кредит за регистрацију (не као периодичан), а угашени нивои су уклоњени (`chutes`/`phind`/`kluster` су обустављени). То је делимично надокнађено добављачем `llm7` (исправних 5M дневно → 150M) и новим бесплатним добављачима (Kilo, OpenCode Zen, Z.AI GLM-Flash).
>
> **Додатно исправљено на ~1,37 милијарди у v3.8.42:** `longcat` је прекласификован са периодичне квоте од 150M месечно на једнократни кредит за регистрацију од 10M након завршетка његовог бесплатног пробног периода. Примењено је исто правило искрености — ниједан добављач није грешком уклоњен.
>
> **Ажурирано 2026-08-26 након повлачења Felo Web-а:** Felo Web је изузет док је порекло/лиценцирање изведено из GPL-а и даље НА ЧЕКАЊУ; извор је у том тренутку пријављивао 38 кључева скупова. Број скупова је актуелан и контролисан кроз CI (`check:docs-counts` обара изградњу ако горенаведени бројеви одступе од `computeFreeModelTotals()`).
>
> **Поново ревидирано 2026-09-02 на основу сопствених страница добављача** (извори: коментари `// evidence:` поред сваког поново ревидираног уноса у `open-sse/config/freeModelCatalog.data.ts`): `gemini` и `ollama-cloud` више не објављују број токена (Google је 2025-12-23 уклонио бесплатну табелу по моделу; Ollama Free план нуди „почетне кредите за коришћење“) и сада су наведени као **неограничени**, те се никада не сабирају (−80M); `groq` има пет ограничења од 200K-TPD **по моделу** (по 6M, +15M), а три повучена ID-а су уклоњена; `nara` има један скуп од 7M дневно (+60M, 210M). Квота добављача `mistral` од 1B видљива је само у конзоли налога — погледајте одељак _Класе доказа_ у Методологији. Извор је у том тренутку пријављивао 35 таквих кључева (−3: `gemini` и `ollama-cloud` су премештени на листу неограничених, а Groq ограничења по моделу нису заједнички скуп).
>
> **Исправљено на ~1,47 милијарди 2026-09-03 (#11773):** `cerebras` је прекласификован са периодичне квоте од 30M месечно (стари пробни период без картице од 1M токена дневно) на једнократни кредит за регистрацију од $5 који захтева начин плаћања. Примењено је исто правило искрености као за LongCat. Извор сада пријављује 34 кључа периодичних скупова и сталну квоту од ~1,47 милијарди.

Највећи **документовани** доприносиоци: `mistral` 1.00B, `nara` 210M, `llm7` 150M, `groq` 30M (пет ограничења по моделу), `cloudflare-ai` 30M, `api-airforce` 24M. (`longcat` је изузет — његов LongCat-2.0 кредит од 10M представља једнократни кредит при регистрацији који захтева KYC, а не периодични месечни буџет.)

> ⚠️ Теоријска горња граница (~10B) увећана је због провајдера који имају само ограничење брзине, али **немају објављено ограничење броја токена** (`tencent`, `siliconflow`, `nvidia`, `baidu`, `glm-cn`, `sparkdesk`), чије би вредности биле `RPM/TPM × 24/7 × 30d` — теоријски максимум који ниједан појединачни налог не може одржати. Они су **изузети** из поуздане вредности (уместо тога су приказани у реду „трајно бесплатно, без ограничења“). То је исто преувеличавање због којег су вишемилијардне тврдње конкурената непоуздане.

## Освежење од 2026-06-17 — шта се променило од 2026-06-05

Пролаз веб-истраживања са 50 агената (званична документација + вести из последњих 7 дана, проверено уз супротстављене изворе) освежио је цео каталог. Најважније:

- **Уклоњено / нема бесплатног нивоа (2026):** `chutes` (бесплатни ниво укинут 2026-03), `phind` (компанија угашена 2026-01), `kluster` (укинут 2026-06-09 → MITO), `gitlawb` + `gitlawb-gmi` (бесплатан приступ за MiMo опозван 2026-05-24, промоција за Nemotron завршена 2026-06 — поново проверено 2026-06-18), `aimlapi` (бесплатни ниво паузиран — поново проверено 2026-06-18), `yi` (Yi-Light повучен, плаћање према потрошњи — поново проверено 2026-06-18), `featherless-ai` (тренутно нема бесплатног нивоа). `iflytek` / `sparkdesk` остају наведени, али уз напомену о опрезу у вези са условима коришћења (Spark Lite је бесплатан; услови коришћења ограничавају употребу проксија/релеја).
- **Gemini** — `2.0 Flash` / `2.0 Flash-Lite` угашени су 2026-06-01, а `2.5 Pro` је напустио бесплатни ниво (2026-04); бесплатни ниво сада обухвата **искључиво породицу Flash** (2.5/3/3.1/3.5 Flash + Gemma). Каталог сада **обједињује** породицу Flash (раније је број био увећан засебним рачунањем сваке варијанте: 462M → 60M).
- **Исправљене вредности:** `cloudflare-ai` 122M → **30M** (стварних 10k неурона дневно), `doubao` је рекласификован као једнократни кредит при регистрацији (не обнавља се), `llm7` 4M → **150M** (документованих 5M токена дневно), `together` крајње тачке „-Free“ су укинуте → уклоњен је и кредит од $25 при регистрацији (захтева се минимална куповина од $5, без бесплатног пробног периода), `longcat` Preview је завршен + Flash модели су повучени → само **LongCat-2.0**, рекласификован као једнократни кредит од **10M** токена при регистрацији (условљен KYC провером, не обнавља се).
- **Откривени нови бесплатни добављачи:** ⭐ **Kilo Code** (`kilo-gateway` — ротирајући скуп „Auto Free“: породица NVIDIA Nemotron 3, StepFun, Poolside, Nex-N2-Pro), ⭐ **OpenCode Zen** (`opencode-zen` — 6 ротирајућих бесплатних модела за програмирање), ⭐ **Z.AI / Zhipu** (`glm-cn` — GLM-4-Flash / 4.5-Flash / 4.7-Flash трајно бесплатни + бонус од 20M при регистрацији) и `arcee-ai` Trinity Large Preview.
- **Нови транспарентни нивои** (погледајте Методологију): категорија _трајно бесплатно, али без ограничења_ (стварни приступ који се обнавља, без ограничења броја токена које би се могло рачунати) и _повећање откључано депозитом_ (OpenRouter $10 → +24M месечно), оба приказана **засебно** како никада не би увећавала истакнути укупан број.

> Детаљна табела по добављачима у наставку представља **снимак стања од 2026-06-05**; горенаведене измене имају предност над њом. Актуелни, канонски извор је каталог по моделима `open-sse/config/freeModelCatalog.ts`.

## Два режима — рачунање наспрам одлучивања

OmniRoute одговара на питање „да ли је бесплатно?“ кроз два режима који намерно читају
различите изворе:

| Режим                      | Извор истине                                                                                                                                                       | Места приказа                                                                                                                        |
| -------------------------- | ------------------------------------------------------------------------------------------------------------------------------------------------------------------ | ------------------------------------------------------------------------------------------------------------------------------------ |
| **Рачунање / приказивање** | Разрешени каталог — испоручена основа преко које се примењује Radar извор (`getRadarCatalog`)                                                                      | Укупне вредности бесплатног нивоа, картица буџета, контролне табле                                                                   |
| **Одлучивање**             | Само испоручени каталог (`FREE_MODEL_BUDGETS` у `open-sse/config/freeModelCatalog.data.ts`) уз локалне хеуристике (суфикс `:free`, нулта цена, `grantsFreeAccess`) | Сваки корисник датотеке `src/shared/utils/freeModels.ts`: увоз модела, усмеравање `auto/*`, `GET /v1/models` и прегледи у прегледачу |

Рачунање се може побољшати кад год је извор доступан. Одлучивање остаје засновано на
артефакту издања, тако да је одговор идентичан у прегледачу и на серверу,
поновљив без мрежне везе и проверљив без базе података. Ако би преглед у
прегледачу читао један извор, а увоз на серверу други, преглед се не би слагао
са оним што се дешава након клика — та подела је задржана
намерно.

## Методологија и напомене

- Бројеви су **процене горње границе** засноване на документованим ограничењима бесплатног нивоа сваког добављача на дан **2026-06-17**, прикупљене веб-истраживањем. Бесплатни нивои се непрестано мењају — поново их проверите пре него што се ослоните на неки податак.
- **Шта нека ставка заправо потврђује.** Ниједна ставка нема оцену поузданости по реду, нити је API пружа — сваки наведени податак сматрајте проценом истог, ненаведеног квалитета. Две чињенице су другачије јер се ручно уређују, а не изводе закључивањем: 5 ставки има независно документовано строго заустављање, а 13 ставки има објаву о коришћењу упита за обучавање. `hardStopGuaranteed` се поставља само када у условима самог добављача пише да ће прекорачење бесплатне квоте довести до одбијања захтева, уместо до прећутног почетка наплате, при чему се извор наводи у коментару поред ставке; никада се подразумевано не поставља на `true`, а ставка коју нико није проверио остаје без постављене вредности. Према томе, одсуство ознаке строгог заустављања значи „није утврђено“, а не „познато је да ће вам бити наплаћено“. **STRICT режим** (опциона заштита усмеравања `freeAccessPolicy=strict`) верује само ставкама које имају ту ознаку; сваки други бесплатни ниво искључује се као `no-hard-stop` (погледајте `open-sse/services/autoCombo/strictZeroCostFilter.ts`).
- `estMonthlyFreeTokens` = само токени који се обнављају месечно. **Једнократни кредити при регистрацији се не обнављају** и рачунају се као 0. Укинути нивои се такође рачунају као 0.
- Дневно ограничење токена → `monthly = daily × 30`. Ако је документован само RPD → `RPD × ~800 излазних токена × 30`. Ако постоји само RPM/TPM (без дневног ограничења) → **неограничено** (погледајте испод).
- **Трајно бесплатно, али без објављеног ограничења токена** (`siliconflow`, `glm-cn`, `tencent`, `baidu`, `kilo-gateway`, `opencode-zen`, `gemini`, `ollama-cloud`): ово је стварни бесплатни приступ који се обнавља, ограничен стопом/истовременошћу. Класификујемо их као `recurring-uncapped` и **никада их не сабирамо** — множење `RPM × 24/7 × 30d` произвело би измишљену горњу границу (такво надувавање одбацујемо). Наведени су да бисте знали да постоје.
- **Повећање квоте уплатом:** једнократна мала допуна која трајно повећава бесплатну квоту (OpenRouter: $10 → 1000 захтева/дан ≈ +24M/месечно). Приказује се као засебан податак и не укључује се у главни податак о сталној квоти.
- **Квоте условљене испуњавањем услова** (`eligibilityGate: "regional-identity"`): стварна квота која се обнавља и постаје доступна тек након провере идентитета везане за регион (данас је то верификација стварног имена у континенталној Кини). Израчунава се применом истог правила уклањања дупликата скупова и приказује као засебан податак (`gatedRecurringTokens`), а никада се не укључује у главни податак о сталној квоти. Режим (`freeType`) остаје непромењен, па се ни усмеравање не мења.
- **Класе доказа.** Правило гласи: број у каталогу наводи свој извор у коментару `// evidence:` поред ставке — `public-page` (страница добављача коју свако може да прочита), `api-public` (неаутентификована крајња тачка добављача, нпр. NaraRouter-ова јавна крајња тачка за планове на router.bynara.id) или `console-verified <date> por <who>` (податак је видљив само у конзоли налога; у коментару се бележи ко га је видео и када, као и јавна страница на којој се наводи да ограничење постоји). Тренутно стање: пет блокова поново проверених 2026-09-02 имају тај коментар (`gemini`, `groq`, `mistral`, `ollama-cloud`, `nara`); ставке које претходе поновној провери од 2026-09-02 наслеђују раније истраживање док не буду измењене; сваки **нови или измењени** број без коментара о доказу представља грешку. Данас је само `mistral` верификован преко конзоле.

## Зашто је наш број мањи него код других агрегатора

Већина вредности „бесплатних токена месечно“ у овој области представља збир вредности наведених за сваки модел. Наша вредност то намерно није:

- **Сваки заједнички пул рачуна се једном.** Бесплатни Mistral план представља једно ограничење од 1B месечно по организацији; навођење тог ограничења под пет модела не чини га ограничењем од 5B. Када би се сабирало по моделу, наш каталог би показивао **~7.4B** (поново израчунато 2026-09-03; ова вредност није контролисана у CI-ју — поново је измерите при свакој промени каталога) — у наслову стоји **~1.47B** јер је то оно што један налог код сваког добављача заиста може да потроши.
- **Дневна ограничења се конвертују, стопе не.** Документовано ограничење токена по дану постаје `× 30`; документовано ограничење захтева по дану постаје `RPD × ~800 токена × 30`; добављач који објављује само број захтева у минуту **нема** месечну вредност и наведен је као _без ограничења_, те се никада не сабира. Множење ограничења стопе са 24/7 јесте надувавање које одбијамо да применимо.
- **Квоте доступне након регионалне провере идентитета приказане су засебно** (`+~6M након регионалне провере идентитета`), јер већина читалаца не може да их користи.
- **Кредити при регистрацији важе само током првог месеца** и приказују се као друга вредност, без спајања са сталном вредношћу.
- **Вредност се проверава путем CI-ја.** `npm run check:docs-counts` поново израчунава укупне вредности из каталога и обара изградњу када ова датотека, README или картица буџета одступе од њих.

## Табела напомена о условима коришћења

> **Ознака ToS је саветодавна, а не препрека за усмеравање.** Добављачи означени са `tos` и даље су подразумевано укључени у усмеравање и комбиновање/резервни избор; ознака се приказује само на `/dashboard/free-tiers` и `/api/free-tier/summary`. ## Речник

| Термин                  | Значење                                                                                       |
| ----------------------- | --------------------------------------------------------------------------------------------- |
| **RPM / RPD / RPH**     | Захтеви у минути / дану / сату                                                                |
| **TPM / TPD**           | Токени у минути / дану                                                                        |
| **Документована квота** | Добављач објављује изричито дневно/месечно ограничење токена (буџет који се може образложити) |
| **Теоријски максимум**  | `ограничење стопе × 24/7 × 30d` — максимум, а не додељени буџет                               |
| **Неурон**              | Cloudflare рачунарска јединица (~1 излазни токен)                                             |
