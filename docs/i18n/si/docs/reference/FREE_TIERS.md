- **සුදුසුකම්-සීමා කළ කෝටා** (`eligibilityGate: "regional-identity"`): කලාපයකට බැඳුණු අනන්යතා පරීක්ෂාවකින් පසුව පමණක් විවෘත වන සැබෑ, නැවත නැවත ලැබෙන කෝටාවකි (වර්තමානයේ චීන ප්රධාන භූමියේ සැබෑ-නම සත්යාපනය). එකම සංචිත-අනුපිටපත් ඉවත් කිරීමේ රීතිය භාවිතයෙන් වෙනම අගයකට (`gatedRecurringTokens`) ගණන් ගන්නා අතර, ස්ථාවර ප්රධාන අගයට කිසිවිටෙක ඇතුළත් නොකෙරේ. පාලන ක්රමය (`freeType`) නොවෙනස්ව පවතින බැවින් මාර්ගගත කිරීමද නොවෙනස්ව පවතී.

## අපගේ සංඛ්යාව අනෙකුත් ඒකාබද්ධකයන්ගේ සංඛ්යාවට වඩා කුඩා වන්නේ ඇයි

මෙම ක්ෂේත්රයේ ඇති බොහෝ "මසකට නොමිලේ ටෝකන" සංඛ්යා එක් එක් මොඩලයට අදාළ ලේබලවල එකතුවකි. අපගේ සංඛ්යාව එසේ නොවන්නේ හිතාමතාමය:

- **සෑම හවුල් සංචිතයක්ම එක් වරක් පමණක් ගණන් කෙරේ.** Mistral හි නොමිලේ සැලැස්ම යනු එක් සංවිධානයකට මසකට 1Bක එක් දීමනාවකි; එය මොඩල පහක් යටතේ ලැයිස්තුගත කිරීමෙන් එය 5Bක් නොවේ. එක් එක් මොඩලය අනුව එකතු කළහොත්, අපගේම නාමාවලියෙහි අගය **~7.4B** වනු ඇත (2026-09-03 දින නැවත ගණනය කරන ලදී; මෙම අගය CI මඟින් පාලනය නොවේ — නාමාවලිය වෙනස් වන සෑම විටම එය නැවත මනින්න) — ප්රධාන ශීර්ෂයෙහි **~1.47B** ලෙස දැක්වෙන්නේ එක් එක් සැපයුම්කරුගේ එක් ගිණුමකට සැබවින්ම වැය කළ හැක්කේ එපමණ බැවිනි.
- **දෛනික සීමා පරිවර්තනය කෙරේ, අනුපාත එසේ නොවේ.** ලේඛනගත tokens/day සීමාවක් `× 30` බවට පත් කෙරේ; ලේඛනගත requests/day සීමාවක් `RPD × ~800 tokens × 30` බවට පත් කෙරේ; requests-per-minute පමණක් ප්රකාශ කරන සැපයුම්කරුවෙකුට මාසික අගයක් **නොමැති** අතර, එය _uncapped_ ලෙස ලැයිස්තුගත කර කිසි විටෙක එකතුවට ඇතුළත් නොකෙරේ. අනුපාත සීමාවක් 24/7න් ගුණ කිරීම අප ප්රතික්ෂේප කරන සංඛ්යා උද්ධමනයයි.
- **ප්රාදේශීය අනන්යතා පරීක්ෂාවකට යටත් කෝටා වෙනම පෙන්වනු ලැබේ** (`+~6M behind regional identity verification`), මන්ද බොහෝ පාඨකයන්ට ඒවා භාවිත කළ නොහැකි බැවිනි.
- **ලියාපදිංචි වීමේ බැර පළමු මාසයට පමණක් අදාළ වේ** සහ ස්ථාවර සංඛ්යාවට කිසි විටෙක මිශ්ර නොකර, දෙවන අගයක් ලෙස වාර්තා කෙරේ.
- **මෙම අගය CI මඟින් බලාත්මක කෙරේ.** `npm run check:docs-counts` නාමාවලියෙන් සමස්ත අගයන් නැවත ගණනය කරන අතර, මෙම ගොනුව, README හෝ අයවැය කාඩ්පත එම අගයන්ගෙන් වෙනස් වූ විට build එක අසාර්ථක කරයි.
