## Кратко — какой объём бесплатного инференса фактически агрегирует OmniRoute?

| Метрика                                              | Токенов в месяц                      | Значение                                                                                                                                                                                                                                                                                                                                               |
| ---------------------------------------------------- | ------------------------------------ | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------ |
| **Документированная регулярная квота**               | **~1.47B**                           | **Пулы** бесплатных тарифов (каталог по моделям), каждый общий пул учитывается **один раз**. Актуальный источник данных для `/api/free-tier/summary` и страницы Free-Tier Budget на панели управления. **Используйте это число.**                                                                                                                      |
| **+ первый месяц с бонусами за регистрацию**         | **~2.07B**                           | Регулярная квота + единоразовые бонусы за регистрацию (Z.AI 20M, DeepSeek 5M, …), с устранением дубликатов на уровне аккаунта. **Только первый месяц** — не возобновляется.                                                                                                                                                                            |
| **+ навсегда бесплатно, без опубликованного лимита** | _не поддаётся количественной оценке_ | `siliconflow`, `glm-cn` (GLM-4-Flash), `tencent`, `baidu`, `kilo-gateway`, `opencode-zen`, `gemini`, `ollama-cloud` — реальный регулярный доступ, ограниченный частотой запросов и параллелизмом, **без лимита токенов, который можно было бы учесть**. Указываются, но никогда не суммируются (мы отвергаем завышение путём подсчёта как `RPM×24/7`). |
| **+ увеличение после пополнения**                    | **+~24M**                            | Единоразовое пополнение OpenRouter на **$10** повышает его бесплатный пул с 50 до 1000 запросов в день. Указывается отдельно, чтобы это никогда не завышало регулярный показатель.                                                                                                                                                                     |
| **+ после региональной проверки личности**           | **+~6M**                             | `modelscope` (привязка Alibaba Cloud + проверка настоящего имени в материковом Китае). Реальная регулярная квота, представленная как `gatedRecurringTokens` / `gatedProviders` и отображаемая на панели управления. Никогда не включается в главный показатель: +~6M после региональной проверки личности.                                             |
| Теоретический максимум (все лимиты частоты, 24/7)    | ~10B                                 | Сумма всех лимитов частоты провайдеров, экстраполированная на непрерывное использование. **Не является гарантией** — не выносите это число в заголовок.                                                                                                                                                                                                |

**Честный заголовок:** _OmniRoute агрегирует **~1.47B документированных бесплатных токенов в месяц** (до ~2.07B в первый месяц с учётом бонусов за регистрацию) в 34 пулах бесплатных тарифов, а также длинный хвост навсегда бесплатных провайдеров без ограничения объёма; сжатие RTK + Caveman (экономия токенов на 15–95%) позволяет увеличить этот объём ещё больше._

> **Почему показатель снизился с прежних ~1.94B.** Обновление от 2026-06-17 — это исправление ради достоверности, а не потеря: для `gemini` теперь устраняются дубликаты общего пула (ранее объём завышался из-за отдельного учёта каждого варианта Flash, 462M → 60M), квота `cloudflare-ai` исправлена до фактических 10k Neurons в день (122M → 30M), `doubao` переклассифицирован как единоразовый бонус за регистрацию (а не регулярный), а закрытые тарифы удалены (`chutes`/`phind`/`kluster` больше не предоставляются). Это частично компенсируется `llm7` (правильное значение 5M в день → 150M) и новыми бесплатными провайдерами (Kilo, OpenCode Zen, Z.AI GLM-Flash).
>
> **Дополнительно исправлено до ~1.37B в v3.8.42:** `longcat` был переклассифицирован из регулярной квоты 150M в месяц в единоразовый бонус за регистрацию в размере 10M после завершения бесплатного предварительного доступа. Применено то же правило достоверности — ни один провайдер не был исключён по ошибке.
>
> **Обновлено 2026-08-26 после вывода Felo Web из эксплуатации:** Felo Web исключён, пока происхождение и лицензирование производного от GPL кода имеют статус HOLD; на тот момент источник сообщал о 38 ключах пулов. Число пулов определяется динамически и контролируется CI (`check:docs-counts` завершает сборку с ошибкой, если приведённые выше числа расходятся с `computeFreeModelTotals()`).
>
> **Повторно проверено 2026-09-02 по собственным страницам провайдеров** (источники: комментарии `// evidence:` рядом с каждой повторно проверенной записью в `open-sse/config/freeModelCatalog.data.ts`): `gemini` и `ollama-cloud` больше не публикуют объём токенов (Google удалила таблицу бесплатных квот для отдельных моделей 2025-12-23; бесплатный тариф Ollama предоставляет «начальные кредиты на использование») и теперь указаны как **неограниченные**, без включения в сумму (−80M); `groq` имеет пять **отдельных для каждой модели** лимитов по 200K TPD (по 6M каждый, +15M), при этом три выведенных из эксплуатации идентификатора удалены; `nara` предоставляет один пул на 7M в день (+60M, 210M). Квота `mistral` в 1B видна только в консоли аккаунта — см. раздел _Классы доказательств_ в методологии. На тот момент источник сообщал о 35 таких ключах (−3: `gemini` и `ollama-cloud` перемещены в список неограниченных, а отдельные для каждой модели лимиты Groq не являются общим пулом).
>
> **Исправлено до ~1.47B 2026-09-03 (#11773):** `cerebras` был переклассифицирован из регулярной квоты 30M в месяц (прежний пробный тариф без карты с 1M токенов в день) в единоразовый бонус за регистрацию в размере $5, для которого требуется способ оплаты. Применено то же правило достоверности, что и для LongCat. Теперь источник сообщает о 34 ключах регулярных пулов и регулярном объёме ~1.47B.

Крупнейшие **документально подтверждённые** источники: `mistral` — 1,00 млрд, `nara` — 210 млн, `llm7` — 150 млн, `groq` — 30 млн (пять лимитов для отдельных моделей), `cloudflare-ai` — 30 млн, `api-airforce` — 24 млн. (`longcat` исключён: предоставляемые им 10 млн для LongCat-2.0 — это разовый регистрационный кредит, доступный после прохождения KYC, а не ежемесячно возобновляемый бюджет.)

> ⚠️ Теоретический предел (~10 млрд) завышен из-за провайдеров, устанавливающих только ограничения частоты запросов и **не публикующих лимит токенов** (`tencent`, `siliconflow`, `nvidia`, `baidu`, `glm-cn`, `sparkdesk`): их показатели рассчитывались бы по формуле `RPM/TPM × 24/7 × 30d` — это теоретический максимум, который не сможет стабильно поддерживать ни одна отдельная учётная запись. Они **исключены** из обоснованного показателя (вместо этого они представлены в строке «бесплатно навсегда, без лимита»). Именно такое завышение делает заявления конкурентов о нескольких миллиардах недостоверными.

## Обновление от 2026-06-17 — что изменилось с 2026-06-05

Весь каталог был обновлён по результатам веб-исследования с участием 50 агентов (официальная документация + новости за последние 7 дней, проверенные в состязательном режиме). Основные изменения:

- **Удалены / бесплатного уровня нет (2026):** `chutes` (бесплатный уровень закрыт в 2026-03), `phind` (компания прекратила работу в 2026-01), `kluster` (закрыт 2026-06-09 → MITO), `gitlawb` + `gitlawb-gmi` (бесплатный доступ к MiMo отозван 2026-05-24, промоакция Nemotron завершилась в 2026-06 — повторно проверено 2026-06-18), `aimlapi` (бесплатный уровень приостановлен — повторно проверено 2026-06-18), `yi` (Yi-Light выведен из эксплуатации, оплата по мере использования — повторно проверено 2026-06-18), `featherless-ai` (на данный момент бесплатного уровня нет). `iflytek` / `sparkdesk` остаются в списке, но снабжены примечанием о необходимости учитывать условия использования (Spark Lite бесплатен; условия использования ограничивают применение в качестве прокси/ретранслятора).
- **Gemini** — `2.0 Flash` / `2.0 Flash-Lite` отключены 2026-06-01, а `2.5 Pro` исключён из бесплатного уровня (2026-04); теперь бесплатный уровень включает **только семейство Flash** (2.5/3/3.1/3.5 Flash + Gemma). Теперь каталог **объединяет** семейство Flash в общий пул (ранее объём был завышен из-за отдельного подсчёта каждого варианта: 462M → 60M).
- **Исправленные значения:** `cloudflare-ai` 122M → **30M** (фактически 10k Neurons в день), `doubao` переклассифицирован как одноразовый бонус за регистрацию (а не периодический), `llm7` 4M → **150M** (документированный лимит — 5M токенов в день), конечные точки `together` с суффиксом "-Free" закрыты → бонус $25 за регистрацию также удалён (требуется минимальная покупка на $5, бесплатного пробного периода нет), предварительная версия `longcat` закрыта + модели Flash выведены из эксплуатации → остался только **LongCat-2.0**, переклассифицированный как одноразовый бонус за регистрацию в размере **10M** токенов (требуется KYC, бонус не возобновляется).
- **Обнаружены новые бесплатные провайдеры:** ⭐ **Kilo Code** (`kilo-gateway` — ротируемый набор "Auto Free": семейство NVIDIA Nemotron 3, StepFun, Poolside, Nex-N2-Pro), ⭐ **OpenCode Zen** (`opencode-zen` — 6 ротируемых бесплатных моделей для программирования), ⭐ **Z.AI / Zhipu** (`glm-cn` — GLM-4-Flash / 4.5-Flash / 4.7-Flash постоянно бесплатны + бонус 20M за регистрацию), а также `arcee-ai` Trinity Large Preview.
- **Новые прозрачные категории** (см. раздел «Методология»): категория _постоянно бесплатных, но без установленного лимита_ (реальный возобновляемый доступ без ограничения по токенам, которое можно было бы учесть) и _повышение лимита после внесения депозита_ (OpenRouter $10 → +24M/мес.); обе отображаются **отдельно**, поэтому они никогда не завышают основной показатель.

## Два режима — подсчёт и принятие решений

OmniRoute отвечает на вопрос «бесплатно ли это?» с помощью двух режимов, которые намеренно используют
разные источники:

| Режим                     | Источник истины                                                                                                                                                              | Где используется                                                                                                                     |
| ------------------------- | ---------------------------------------------------------------------------------------------------------------------------------------------------------------------------- | ------------------------------------------------------------------------------------------------------------------------------------ |
| **Подсчёт / отображение** | Разрешённый каталог — поставляемая базовая версия с наложенными данными из ленты Radar (`getRadarCatalog`)                                                                   | Общие показатели бесплатного уровня, карточка бюджета, панели мониторинга                                                            |
| **Принятие решений**      | Только поставляемый каталог (`FREE_MODEL_BUDGETS` в `open-sse/config/freeModelCatalog.data.ts`) плюс локальные эвристики (суффикс `:free`, нулевая цена, `grantsFreeAccess`) | Все потребители `src/shared/utils/freeModels.ts`: импорт моделей, маршрутизация `auto/*`, `GET /v1/models` и предпросмотр в браузере |

Подсчёт может становиться точнее всякий раз, когда доступна лента данных. Принятие решений остаётся привязанным к
артефакту релиза, поэтому ответ одинаков в браузере и на сервере,
воспроизводим офлайн и тестируем без базы данных. Если бы предпросмотр в браузере
использовал один источник, а серверный импорт — другой, предпросмотр расходился бы
с тем, что происходит после нажатия, поэтому такое разделение сохранено
намеренно.

## Методология и оговорки

- Числа являются **оценками верхней границы**, основанными на документированных ограничениях бесплатного уровня каждого провайдера по состоянию на **2026-06-17** и собранными посредством веб-исследования. Бесплатные уровни постоянно меняются — перепроверяйте данные, прежде чем полагаться на какую-либо цифру.
- **Что на самом деле подтверждает каждая запись.** У записей нет индивидуальной оценки достоверности, и API её не предоставляет — рассматривайте каждую приведённую выше цифру как оценку одинакового, явно не указанного качества. Два факта отличаются, поскольку они проверяются вручную, а не выводятся автоматически: для 5 записей независимо документирована жёсткая остановка, а для 13 записей раскрыта информация об обучении на промптах. `hardStopGuaranteed` устанавливается только в том случае, если в собственных условиях провайдера указано, что при превышении бесплатной квоты запрос будет отклонён, а списание средств не начнётся автоматически; источник указан в комментарии рядом с записью. Значение никогда не устанавливается в `true` по умолчанию, а у непроверенной записи оно остаётся незаданным. Поэтому отсутствие флага жёсткой остановки означает «не установлено», а не «известно, что с вас начнут списывать деньги». **Режим STRICT** (включаемое по желанию ограничение маршрутизации `freeAccessPolicy=strict`) доверяет только записям с этим флагом; все остальные бесплатные уровни исключаются как `no-hard-stop` (см. `open-sse/services/autoCombo/strictZeroCostFilter.ts`).
- `estMonthlyFreeTokens` = только ежемесячно возобновляемые токены. **Одноразовые бонусы за регистрацию не возобновляются** и учитываются как 0. Прекращённые уровни также учитываются как 0.
- Дневной лимит токенов → `monthly = daily × 30`. Если документирован только RPD → `RPD × ~800 выходных токенов × 30`. Если указаны только RPM/TPM (без дневного лимита) → **без лимита** (см. ниже).
- **Постоянно бесплатно, но опубликованного лимита токенов нет** (`siliconflow`, `glm-cn`, `tencent`, `baidu`, `kilo-gateway`, `opencode-zen`, `gemini`, `ollama-cloud`): это реальный постоянный бесплатный доступ, ограниченный частотой запросов или параллелизмом. Мы классифицируем такие уровни как `recurring-uncapped` и **никогда не включаем их в сумму** — умножение `RPM × 24/7 × 30d` дало бы фантастический потолок (мы отвергаем такое завышение). Они перечислены, чтобы вы знали об их существовании.
- **Увеличение лимита после пополнения:** небольшое одноразовое пополнение, навсегда повышающее бесплатную квоту (OpenRouter: $10 → 1000 запросов в день ≈ +24 млн в месяц). Указывается отдельной цифрой и не включается в основной показатель постоянной квоты.
- **Квоты с ограничениями по соответствию требованиям** (`eligibilityGate: "regional-identity"`): реальная возобновляемая квота, которая становится доступна только после проверки личности, привязанной к определённому региону (сейчас — проверка по настоящему имени в материковом Китае). Учитывается с применением того же правила устранения дублирования общих пулов в отдельном показателе (`gatedRecurringTokens`) и никогда не включается в основной показатель постоянной квоты. Режим (`freeType`) не меняется, поэтому маршрутизация также остаётся неизменной.
- **Классы доказательств.** Правило: число в каталоге должно сопровождаться ссылкой на источник в комментарии `// evidence:` рядом с записью — `public-page` (страница провайдера, доступная всем), `api-public` (не требующая аутентификации конечная точка провайдера, например публичная конечная точка тарифов NaraRouter по адресу router.bynara.id) или `console-verified <date> por <who>` (цифра видна только в консоли учётной записи; в комментарии указывается, кто и когда её видел, а также публичная страница, подтверждающая существование лимита). Текущее состояние: пять блоков, повторно проверенных 2026-09-02, содержат такое доказательство (`gemini`, `groq`, `mistral`, `ollama-cloud`, `nara`); записи, существовавшие до повторной проверки 2026-09-02, наследуют результаты более раннего исследования, пока их не изменят; любое **новое или изменённое** число без комментария с доказательством является ошибкой. На сегодняшний день только `mistral` имеет статус `console-verified`.

## Почему наша цифра меньше, чем у других агрегаторов

Большинство показателей «бесплатных токенов в месяц» в этой сфере представляют собой суммы значений, указанных для каждой модели. Наша цифра намеренно рассчитывается иначе:

- **Каждый общий пул учитывается один раз.** Бесплатный план Mistral предоставляет один лимит в 1B токенов в месяц на организацию; перечисление его для пяти моделей не превращает этот лимит в 5B. При суммировании по моделям наш собственный каталог показывал бы **~7.4B** (пересчитано 2026-09-03; эта цифра не контролируется CI — пересчитывайте её при каждом изменении каталога), однако в заголовке указано **~1.47B**, поскольку именно столько фактически может использовать один аккаунт у каждого провайдера.
- **Суточные лимиты пересчитываются, ограничения скорости — нет.** Задокументированный лимит токенов в день преобразуется как `× 30`; задокументированный лимит запросов в день — как `RPD × ~800 токенов × 30`; если провайдер публикует только количество запросов в минуту, для него **не указывается** месячный объём и он помечается как _безлимитный_, но никогда не включается в сумму. Умножение ограничения скорости на режим 24/7 — это завышение, от которого мы отказываемся.
- **Квоты, доступные после региональной проверки личности, показываются отдельно** (`+~6M после региональной проверки личности`), поскольку большинство читателей не могут ими воспользоваться.
- **Кредиты за регистрацию действуют только в первый месяц** и указываются второй отдельной цифрой, никогда не объединяясь с постоянным объёмом.
- **Значение контролируется CI.** `npm run check:docs-counts` пересчитывает итоговые значения на основе каталога и завершает сборку с ошибкой, если данные в этом файле, README или карточке бюджета перестают им соответствовать.

- **`veoaifree-web`** — В поставляемом freeNote указано «6 запросов/час», однако в настоящее время такой явный лимит нигде на veoaifree.com не задокументирован. Сайт заявляет о неограниченной бесплатной генерации без входа в систему. Перечисленные модели…
- **`voyage-ai`** — Поставляемое freeNote «200M бесплатных токенов для эмбеддингов и реранжирования» в целом верно по количеству токенов, но вводит в заблуждение: в нём не указано, что это однократная квота на аккаунт, а не возобновляемая…
- **`yi`** — Поставляемое freeNote «Бесплатные модели Yi-Light» ссылается на название модели («Yi-Light»), которое отсутствует во всей актуальной документации и каталоге моделей 01.AI — такая модель не указана на platform.01.ai, …

## Глоссарий

| Термин                      | Значение                                                                                            |
| --------------------------- | --------------------------------------------------------------------------------------------------- |
| **RPM / RPD / RPH**         | Запросы в минуту / день / час                                                                       |
| **TPM / TPD**               | Токены в минуту / день                                                                              |
| **Документированная квота** | Провайдер публикует явное суточное/месячное ограничение на количество токенов (обоснованный бюджет) |
| **Теоретический максимум**  | `rate-limit × 24/7 × 30d` — максимум, а не гарантированный бюджет                                   |
| **Нейрон**                  | Единица вычислений Cloudflare (~1 выходной токен)                                                   |
