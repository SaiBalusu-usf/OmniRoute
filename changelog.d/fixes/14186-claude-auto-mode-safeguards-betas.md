- **fix(claude):** Claude Code auto mode now gets its permission checks from the server again when routed through OmniRoute. Claude Code sends a `safeguards` body field with the `afk-mode-2026-01-31` and `dangerous-tool-use-2026-09-03` betas, and the server runs the checks inside the same request. Both betas were missing from `FORWARDABLE_CLIENT_BETAS`, so OmniRoute dropped them. Claude Code then showed "this session isn't eligible" and fell back to its own separately billed classifier requests. See the [auto mode classifier billing docs](https://code.claude.com/docs/en/auto-mode-classifier-billing) ([#14186](https://github.com/diegosouzapw/OmniRoute/pull/14186))
